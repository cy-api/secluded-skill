# Secluded 词库校验规范 / Word Library Checking Spec

本规范由原 scripts/check_wordlib.py 的校验逻辑改写而来，任何 AI 无需 Python 环境即可按规则逐项检查词库。
This spec was derived from the original scripts/check_wordlib.py logic so any AI can check word libraries rule-by-rule without a Python environment.

用法 / Usage：写完词库后按下方 7 类检查逐项核对；修复全部「错误」，逐条审视「警告」后再交付。
After writing a library, verify each of the 7 checks below; fix all Errors, review all Warnings, then deliver.

---

## 1. 变量名字节 / Variable Name Bytes 【错误 / Error】

规则 / Rule：赋值行变量名（冒号前的名字）按 UTF-8 编码必须是 **1 或 3 字节**——1 个字母，或 3 个字母，或 1 个汉字。其他字节数会被引擎当文本输出。
流程 / Procedure：逐行找 `名字:值` 形式，取名字计算 UTF-8 字节数。
跳过 / Skip：`如果` / `elif` / `else` 等流程控制行不检查。

| 示例 Example | 字节 Bytes | 结论 Verdict | 修复 Fix |
|---|---|---|---|
| `A:666` | 1 | ✅ | - |
| `API:$访问 url$` | 3 | ✅ | - |
| `名:@API[name]` | 3 | ✅ | - |
| `当前值:5` | 9 | ❌ 会被当文本输出 | 改 3 字节名，如 `CUR:5` |

## 2. % 配对与转义 / % Pairing & Escaping 【错误 / Error】

规则 / Rule：每行未转义的 `%` 必须是**偶数个**（成对）。不是变量引用的 `%` 必须写成 `\%`。
流程 / Procedure：逐行统计未被 `\` 转义的 `%` 个数，奇数个即报错。
修复 / Fix：文本中的百分号写 `\%`；漏写结束 `%` 则补上。
示例 / Example：`可用度%安卓系统%` → 奇数个 `%`，若 安卓系统 不是变量应改 `可用度\%安卓系统\%`。

## 3. 非内置变量引用 / Undefined Variable Reference 【警告 / Warning】

规则 / Rule：引用 `%变量%` 时，该变量必须是内置变量或词库内已定义（冒号赋值）。
流程 / Procedure：对每个 `%名字%`，若不在内置清单且词库内从未定义过，提示确认。
内置变量参考 / Built-in reference：群主QQ、QQ、群、群号、时间戳毫秒、时间戳进程、上线模式、消息来源、括号1、括号2、括号3、随机数、空格、换行、回车、当前时间、日期、昵称、用户昵称、图片、语音、文本、原文本（以 references/Secluded变量大全.txt 为准）。

## 4. 词汇头过宽 / Over-broad Header 【警告 / Warning】

规则 / Rule：词汇头不应匹配过大的消息范围。
需注意 / Watch out：纯数字匹配 `([0-9]+)` 会拦截所有数字消息；全匹配 `([\s\S]*)` 触发面过大。命中时建议加前缀限定。

## 5. 连续空行 / Consecutive Blank Lines 【警告 / Warning】

规则 / Rule：空行是块分隔符；块间保留一个空行，多余空行易导致块误截断，块内不得有空行。
流程 / Procedure：连续两个及以上空行即提示清理。

## 6. 末尾 AI 生成注明 / Trailing AI Disclaimer 【错误 / Error】

规则 / Rule：文件末尾不得出现「AI生成 / 内容由AI生成 / 仅供参考 / ChatGPT 生成」等说明、署名、水印或多余行——会被引擎当词库内容解析导致运行异常。
流程 / Procedure：检查文件最后 300 字，命中即删。

## 7. 最后一行字面 \n / Trailing Literal \n 【警告 / Warning】

规则 / Rule：最后一行末尾不加字面 `\n`。
修复 / Fix：删除末行结尾的 `\n`。

---

## 附加项 / Extra Checks

- 文件不能为空 / File must not be empty
- 疑似函数嵌套 / Suspected function nesting：单行出现 4 个以上 `$`，检查是否"函数不套娃"
- 注释与特殊行 / Comment & special lines：行首 `//`、`##`、`&&` 为注释；`[系统消息]` 行、`:` 开头行为特殊块，不参与变量名检查

## 验收 / Acceptance

- 错误项必须全部清零 / All Errors must be zero
- 警告项逐条判断，确认无影响后可保留 / Review each Warning; keep only when confirmed harmless
