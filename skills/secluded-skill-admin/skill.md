# 管理功能域（Admin）

专攻管理类词库：群管理、权限、监控、统计。覆盖范围**宽泛但不越界**——凡是"管群、管人、管数据"的功能都归入本域；游戏娱乐类请用 `secluded-skill-fun`。

**参考词库**（写同类功能前必读，原样位于 references/）：
- `references/群管词库.txt`：群管完整范例（889 行）
- `references/发言统计.txt`：统计排行范例（89 行）

## 1. 权限校验链（管理词库核心）

权限从高到低：**全局主人 → 主人 → 群主 → 管理员 → 手动白名单**。

| 身份 | 判断方式 |
|---|---|
| 全局主人 | `如果:%QQ%==%全局主人%`（初始化 `$全局变量 全局主人 QQ$`） |
| 主人 | `$主人列表` / `$添加主人 QQ$` |
| 群主 | `如果:%QQ%==%群主QQ%`（内置变量） |
| 管理员 | `如果:$管理员 %群号% %QQ%$`（返回真即管理员） |
| 白名单 | `$写 白名单 成员 QQ$` 后 `如果:$存在 ...` |

**推荐模板**——独立校验词汇 + `$回调` 复用，结果存 1 字节变量：

```
[内部]群管校验
Q:0
如果:%QQ%==%群主QQ%|$管理员 %群号% %QQ%$|%QQ%==%全局主人%
Q:1
返回
如果尾

[内部]管理操作
$回调 群管校验$
如果:%Q%==0
操作失败：无权限（需群主/管理员）
返回
如果尾
```

## 2. 开关与配置读写

配置按群号隔离，读写用 `$读/$写`，路径键可用中文：

```
$读 群管示例/配置/%群号%.txt 总开关 1$
$写 群管示例/配置/%群号%.txt 总开关 0$
```

- 默认值给 `1`（开）或 `0`（关），先读后判
- 布尔映射可省多行：`z:{"开启":1,"关闭":0}` + `@z[%括号1%]` 写入
- 全局配置（跨群）单独存一份：`$读 群管示例/全局配置 发送格式 文本$`，初始化时 `$全局变量` 缓存

## 3. 黑名单 / 违禁词 / 进群验证

- **黑名单**：`$键列表 路径 存在 QQ$` 判断成员是否在名单；总处理里先查后放行：

```
如果:$键列表 群管示例/黑名单/%群号%.txt 存在 %QQ%$|$键列表 群管示例/全局黑名单 存在 %QQ%$
$调用 黑名单处理$
返回
如果尾
```

- **违禁词**：全局变量做开关（`$全局变量 违禁词检测%群号% 1$`），命中时调用检查词汇
- **进群验证**：开关写配置，新成员验证逻辑独立成词汇块

## 4. 统计与排行（发言统计类）

- **数据按天隔离**：`发言统计/%群号%/%时间yyyy%%时间MM%%时间dd%/%QQ%`，次日自动重置
- **累计数据单独存**：`发言统计/累计/%群号%/%QQ%`
- **排行计算模板**（内部词汇 + 标签跳转 + 群成员列表）：

```
[内部]排行计算
$GroupMemberListGet %群号% list$
L:$消息数量 list Uin$
I:0
:loop
如果:%I%>=10|%I%>=%L%
$标签跳转 loop尾$
如果尾
...（遍历群成员读次数、比较大小、组装榜单）
I:[%I%+1]
$标签跳转 loop$
:loop尾
%榜%
```

- 空榜判断：`如果:$存在 %榜% 条`（榜单为空时给占位文案）
- 统计入口用 `[总处理]` 或 `[总处理]:%Text%` 挂接，先过滤机器人自身：`如果:%QQ%==%登录账号% 返回 如果尾`

## 5. 监控与心跳

- 系统监控类词汇：读设备状态（处理器利用/内存利用/储存可用）组装面板文本
- 心跳：`[系统消息]心跳` 定时刷新全局缓存（如群权限），用 `$JSON 长度` + 标签跳转遍历群列表
- 预加载：`[系统消息]词库初始化` 调 `$调用 预加载$`，一次性缓存全局配置到 `$全局变量`

## 6. 菜单与发送格式

- 管理菜单仅权限者可见：入口词汇先 `$回调 群管校验$`，`%Q%==0` 直接拒绝
- 面板文案统一模板：`时间戳 + 分隔线 + 功能项 + 欢迎语`，用 `\n` 控制换行
- 发送格式做成全局配置（`$写 配置 发送格式 文本$`），回复统一 `$调用 发送格式$` 组装

## 7. 授权功能提示（重要）

以下管理能力属于 Secluded **授权函数**，默认不写：修改群管理员、修改专属头衔、被禁言列表、群申请同意/拒绝/忽略、免打扰设置、群打卡、表情回应、群代办、拍一拍、邀请好友进群、精华消息、匿名/灰色消息等（完整清单见主技能 `SKILL.md` 第 14 章）。用户需求涉及这些功能时，按主技能第 14 章三选一提问确认（原生函数效果 / 文本同类效果 / 其他），账号已声明 Secluded 授权才可写。

## 8. 本域踩坑

- 校验变量必须 1 字节（`Q`）或 3 字节，禁止 9 字节中文名
- 菜单项之间用 `\n` 分隔，文件内直接换行会被拼接
- 统计路径的日期变量用 `%时间yyyy%` 等内置变量拼目录，不要自己造
- 遍历群成员/榜单的循环必须设上限（`%I%>=10`），防止超长
