# 娱乐功能域（Fun）

专攻娱乐类词库：游戏、抽奖、挂机、收集、商店。覆盖范围**宽泛但不越界**——凡是"玩"的功能都归入本域；群管理/统计类请用 `secluded-skill-admin`。

**参考词库**（写同类功能前必读，原样位于 references/）：
- `references/钓鱼娱乐.txt`：完整娱乐词库范例（604 行）

## 1. 游戏数据目录结构

所有玩家数据统一存 `数据/<游戏名>/` 下，按物品/状态分文件、按 QQ 做键：

```
数据/钓鱼系统/物品/贝壳 %QQ%
数据/钓鱼系统/物品/石头 %QQ%
数据/钓鱼系统/钓鱼开 %QQ%
数据/钓鱼系统/钓鱼时间/钓鱼开关 %QQ%
数据/钓鱼系统/族钓 %QQ%
```

- 读写一律 `$读/$写`，默认值给 `0`
- 物品类用"物品子目录 + 单文件单物品"或"单文件多键"都行，保持一致即可

## 2. 随机数与概率事件

- 范围随机：`S:%随机数2-10%`（或 `$随机数 最小 最大$`）
- 概率分支：随机 1~N，`如果:%A%==1` / `==2` ... 分派不同结果（掉落物/失败/特殊事件）
- 概率事件必须留"保底"分支（如断竿扣道具），不能所有分支都掉好东西

```
A:%随机数1-5%
如果:%A%==1
（掉落贝壳）
如果尾
如果:%A%==2
（掉落石头）
如果尾
...
```

## 3. 挂机 / 定时结算

- 开启挂机：写开关 + 延时回调：

```
$写 数据/钓鱼系统/钓鱼开 %QQ% 1$
$调用 36000000 结束挂机钓鱼$
```

- 结算词汇（`[内部]结束挂机钓鱼`）：先读开关确认状态，再随机产出，最后关开关
- 延时单位是毫秒（10 小时 = 36000000），结束后自动回调对应词汇
- 状态机：开启前读当前状态，已开启则提示"等收货后再来吧"，防止重复挂机

## 4. 图鉴 / 仓库 / 商店

- **图鉴**：静态菜单列出所有可获取物品
- **仓库（我的鱼库）**：遍历读取该玩家各物品数量，组装清单：

```
贝:$读 数据/钓鱼系统/物品/贝壳 %QQ% 0$
石:$读 数据/钓鱼系统/物品/石头 %QQ% 0$
（每类物品一个变量，逐行展示）
```

- **商店**：菜单 + 价格表，购买时读持有量、扣减、写回

## 5. 菜单与入口

- 主入口菜单统一一行两项：`🎣.钓鱼` `🎰.鱼类图鉴` `🐟.我的鱼库` `🤖.挂机钓鱼` `💵钓鱼商店`
- 子功能独立词汇块，触发词带前缀避免过宽（如"钓鱼"而非裸 `([0-9]+)`）
- 装饰性文案（分隔线、水印框）用 `\n` 组装，保证对齐美观

## 6. 特权与门槛设计

- 特权通行证：`$读 数据/钓鱼系统/特权通行证 %QQ% 0$`，无特权直接拒绝并提示
- 道具门槛（如鱼竿/族钓）：操作前检查，没有则提示"先去获得道具"
- 门槛检查放词汇开头，减少无效计算

## 7. 授权功能提示（重要）

以下娱乐效果属于 Secluded **授权函数**，默认不写：猜拳、骰子、闪字、戳一戳/窗口抖动、视频消息、泡泡消息、语音消息（>3MB）、自定义 JSON 消息等（完整清单见主技能 `SKILL.md` 第 14 章）。用户需求涉及这些效果时，按主技能第 14 章三选一提问确认（原生函数效果 / 文本同类效果 / 其他），账号已声明 Secluded 授权才可写。

## 8. 本域踩坑

- 随机变量名用合法字节（`A`、`S`、`鱼` 等），禁止 9 字节中文名
- `$调用 毫秒 词汇$` 的延时回调词汇必须用 `[内部]` 前缀，避免被外部触发
- 所有写操作都要先读旧值再加/减后写回：`$写 ... [%旧%+%鱼%]$`
- 回复文案里含 `%` 时记得转义 `\%`
- 定时回调结束后必须重置开关，否则玩家卡在挂机状态
